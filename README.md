# mcpfleet-obs

Shared error taxonomy, metrics middleware, and client tracking for the mcpfleet MCP servers. This package provides standardized error handling, Prometheus instrumentation, and distributed tracing utilities for FastMCP v3+ applications in the mcpfleet ecosystem. See the [error shapes probe report](https://file:///home/bch/dev/mcpfleet/probes/fastmcp-error-shapes/PROBE-REPORT.md) for detailed FastMCP error taxonomy research.
